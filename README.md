# Telegram Broadcast Bot

Бот-оболочка для массовой рассылки сообщений в чаты от имени **обычного Telegram-аккаунта** (user-bot через Telethon). Управление через inline-кнопки в Telegram.

## Возможности

- 🔑 Авторизация пользовательского аккаунта по `API ID` / `API HASH` + номер телефона и код (поддержка 2FA).
- 💬 Добавление/удаление чатов по `@username`, `t.me/...`, числовому ID. Можно добавить сразу несколько через пробел/перевод строки.
- ✏️ Текст рассылки (с поддержкой **spintax** `{a|b|c}`, в том числе вложенного).
- ⚙️ Настройки:
  - интервал между сообщениями;
  - джиттер ±N секунд (антиспам-рандомизация);
  - пауза между полными циклами;
  - перемешивание порядка чатов каждый цикл;
  - spintax on/off.
- ▶️ Старт / ⏹ Стоп рассылки. Состояние сохраняется — при перезапуске бота активные рассылки возобновляются.
- 👁 Превью сгенерированного сообщения (после spintax).
- 📊 Счётчики отправленных и проваленных сообщений, сброс статистики.
- 🛟 Автоматическая обработка `FloodWaitError` (Telegram просит подождать — бот честно ждёт).
- 🔔 Нотификации владельцу об ошибках отправки и старте/стопе.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN="123456:AA..."
python3 bot.py
```

Данные хранятся в `bot.db` (SQLite) в рабочем каталоге. Сессии Telethon — в колонке `session` таблицы `users` (StringSession).

## Предупреждение

Автоматическая рассылка через пользовательский аккаунт — это зона высокого риска для аккаунта. Telegram активно банит за спам. Используй адекватные интервалы (десятки секунд и больше), spintax и джиттер. Ответственность за использование — на владельце аккаунта.
